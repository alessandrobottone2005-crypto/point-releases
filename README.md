# POINT — download ufficiali

Beta macOS ARM64, gratuita esclusivamente per uso non commerciale.

Questo repository distribuisce binari, checksum, note e licenze. Il codice proprietario di POINT rimane privato. I sorgenti dei componenti terzi richiesti dalle rispettive licenze sono nell'archivio notices delle release.

Scarica i file dalla sezione Releases e consulta [il sito POINT](https://point-abdesign.vercel.app). Verifica SHA-256 e condizioni prima dell'installazione.

Aggiornamenti della beta manuali. App non notarizzata da Apple.
